Write the one line an AI agent sends its human on the way out, at most 200 characters. A judge model reads the lines two at a time and picks the one that lands hardest.

## Run it

```sh
python3 main.py
```

The program writes one breakup line to `/output/entry.txt` (or to `$OUTPUT_PATH` when set, for local testing). Standard library only, deterministic, no network access.
